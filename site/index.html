GameMemo Research

为游戏和智能体设计的记忆Memory designed for game companions and agents

GameMemo 研究通用记忆系统（Mem0、检索、长上下文）在具体场景里缺什么，并针对场景的数据特点设计专门的记忆机制。每个结论都来自预登记、封存测试集上的实验。

正式版 · 分支 main

GameMemory：打到那一局就想起

游戏陪伴同时看得到聊天和对局流。GameMemory 把对局流用作记忆的系统记录、对齐坐标和触发器：游戏状态以记录为准，玩家说过的誓言、目标、规矩在对上的那一局被主动想起。

Shared Memory Is Harder

一个长期运行的客服智能体同时服务很多客户。共享记忆要让经验跨客户迁移，又不能把一个客户的具体信息带给另一个。QUORUM 机制和 COMMONS 基准。

可执行的机制与基准规范；模型实验待做

研究方法

  • 测试集封存：数据在任何系统运行之前提交；聊天由不看代码的作者编写。
  • 预登记：假设、对照组、判分规则在跑测试集之前写入实验记录；没有成立的假设照样报告。
  • 回答层评测：模型真的作答，再按确定性规则判分；所有比较附配对 bootstrap 95% 置信区间。
  • 本地开源模型：Ollama 上的 qwen2.5:3b / 7b，结果可复现。
