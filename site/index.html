GameMemo Research

面向场景结构的智能体记忆Memory structures for agents, derived from the structure of their data

通用的智能体记忆把交互历史当作文本，按查询检索。GameMemo 研究两类场景中这一假设的失效，并针对场景的数据结构提出相应的记忆结构。所有结论来自预登记、测试集封存的实验。

技术报告 · 分支 main

Event-Grounded Memory for Game Companions

游戏陪伴同时观察对话流与对局流。我们提出事件流记忆：由对局流构造事件流作为系统记录，把对话锚定到事件以解析指代，把意图编译为事件触发条件。在信息对等的比较中，事件流记忆在游戏状态问答与事件触发回忆两项任务上显著优于改写式、检索式与长上下文记忆。

技术报告 · 分支 shared-memory

Confidence-Based Updating of Shared Memory for Multi-Tenant Agents

多租户智能体的共享记忆需要在经验迁移与租户隔离之间取舍。我们主张共享记忆应基于独立租户证据的置信度更新，并以条件限定适用范围。在 COMMONS-1 上，原始记录共享与改写式共享分别出现实例泄露与伪泛化，基于置信度的结构化共享在两个模型上均为零污染。

研究方法

  • 测试集封存。数据在任何系统运行之前固定并提交；对话文本由不接触被测代码的作者编写。COMMONS-1 的数据文件因 .gitignore 规则在测试后才进入仓库，已验证与运行所用文件逐字节一致，详见其实验记录。
  • 预登记。假设、对照与判分规则在测试前写入实验记录；未成立的假设照常报告。
  • 信息对等。基线与所提方法获得相同的输入，差别仅在记忆结构。
  • 回答层评测。模型实际作答，按确定性规则判分；比较附配对 bootstrap 95% 置信区间。
  • 可复现。本地开源模型（Ollama 上的 qwen2.5:3b / 7b），温度 0，代码、数据与结果文件随仓库发布。
