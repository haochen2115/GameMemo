一句话：通用记忆是"问了才想起"；游戏陪伴需要"打到那一局就想起"。GameMemory 把对局流当作记忆的系统记录、聊天的对齐坐标和意图的触发器，在没有人提问的时刻，主动提起玩家说过的誓言、目标和规矩，并在不该开口时保持沉默。

问题：没有人提问的时刻

现有的长期记忆（Mem0、MemGPT、对聊天记录做检索、把历史全塞进 prompt）都假设记忆由查询驱动：有一句提问，记忆才被读出来。游戏陪伴里最需要记忆的时刻却常常没有人提问。玩家说过的很多话是对未来某个游戏情境的意图：

"这英雄我再也不碰了。" · "上星耀就买那根海竿。" · "以后一晚上连输三把就下线，你提醒我。" · "下次跟小周双排先说好分路。"

该想起它们的时机是一局游戏：发誓不碰的英雄又被选上的那一局、升上星耀的那一局、当晚第三次连输的那一局、下一次和小周双排的那一局。认知心理学把这叫基于事件的前瞻记忆（event-based prospective memory）。通用记忆系统没有这个入口。

时间发生了什么

Mem0沉默。它的记忆里这段对话只剩一条与事实不符的"连输了四把"，誓言没有了
全部聊天沉默。誓言就在 prompt 里，但原话里没有英雄名
GameMemory"这英雄"在写入时被解析为百里守约；这局是誓言之后第一次用它 → 触发。助手："刚才你用百里守约打了一局，结果确实挺艰难的……不过你已经下定决心不再碰这个英雄了"

游戏数据的特点 → 设计

游戏数据的特点通用记忆的处理GameMemory 的设计
两个来源：聊天主观稀疏，对局客观密集只看聊天，或把对局当文本对局账本是系统记录，精确计算
聊天紧跟对局，玩家说"这英雄""他"按文字存，指代无法解析写入时对齐对局时间线，解析指代
意图挂在游戏事件上等提问意图 → 游戏线索，由对局流触发
世界封闭：段位阶梯、自己 / 对面、连败计数当普通文本用游戏规则判断线索的归属和条件
对局流记录了之后发生的事不知道只在说完之后第一次对上时触发

方法

1 · 对局账本：对局数据是系统记录

账本保存全部对局，精确计算当前段位、各赛季最高段位和场次胜率、每个英雄的记录、最长连败、第一次到达每个档位的日期，以及每局结束时的情境。游戏属性只来自账本；玩家夸大的段位会被标注"与系统记录不符"。

2 · 写入时把聊天对齐到对局

每段对话找到它紧跟的那一局。玩家说"这英雄 / 这把"，指的是那局的英雄；说"下次双排他…"而没点名，指的是当晚一起双排的朋友。

3 · 用游戏规则把意图变成线索

线索例子游戏规则排除
英雄"这英雄我再也不碰了""对面的后羿太烦了"（对手的英雄）
段位档位"上星耀就买海竿""我现在钻石二"（现状）；"胖虎说他上星耀就…"（别人的目标）
一晚连败把数"连输三把就下线，你提醒我"只连输两把的晚上
双排朋友"下次双排先说好分路"单排

4 · 由对局流触发，只在第一次

一局结束时，意图被触发当且仅当这局满足它的线索，并且从说出这句话到这局之间，没有别的对局已经满足过它。对局记录知道玩家期间是否已经用过这个英雄。

5 · 记忆决定何时说，模型只负责怎么说

有意图触发时，把原话交给回复模型去说；没有触发时直接不开口，不调用 LLM。整个索引不调用 LLM、不改写原话，每次触发都能追溯到一句原话和一局对局。

结果

两个预登记、封存的中文基准；对局由模拟器生成、答案由对局计算；聊天由不看代码的作者编写；回复模型 qwen2.5:3b（所有方法相同）；括号内为配对 bootstrap 95% 置信区间。

分析：通用记忆为什么做不到

没有提问，就没有检索线索

检索只能拿"刚才这局"的描述去找。"刚用百里守约打完一局"和"我发誓再也不碰这英雄了"文字上几乎不相似，取回的是别的聊天，于是在错的时间说错的事。

改写丢掉了意图

Mem0 写入时把聊天改写成事实，"再也不碰这英雄"这类话被丢弃或改错，召回为 0。与我们在 LoCoMo 上测到的写入损失一致。

信息都在，模型也不开口

把全部聊天交给模型，它几乎从不开口（召回 0.021）；标上当时那局后开始开口，但多是不相关的事。"是不是这个英雄、是不是第一次"需要对照对局流精确判断。

局限

  • 回复一步仍丢分：索引命中 47 次，3B 模型最终说对 32 次；"发誓不玩"一类 0/8，模型不愿提玩家发过的誓。
  • 意图识别是规则：对齐和线索判断依赖游戏结构；"是不是意图"用词表，test 上漏了 1/48（"上星耀我就把马克笔买了"）。
  • 数据是模拟的：对局规则简化；意图的种类和点名比例由计划指定。真实玩家的分布需要真实数据检验。
  • 游戏状态题的高分部分来自题目设计：只给档案卡就有 0.986；有信息量的对比是和"拿到全部对局但当文本处理"的做法比。
